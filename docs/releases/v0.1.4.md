# v0.1.4

同一 Webhook 群运营批次只创建一个企微群发任务，完整 `chat_id_list` 包含所有冻结目标。CLI 的调用仍只需计划 ID、话术和已有小程序素材 ID，明确选择 `--all-bound-groups`。

```sh
aicrm-cli group-ops webhook push \
  --plan-id 12 \
  --text '这里填写要推送的话术。' \
  --miniprogram-id 1195 \
  --all-bound-groups
```

自动分页、随机事件、0600 原始请求快照、同事件固定范围/正文恢复、签名隔离和写请求不自动重试继续保留。`push --dry-run` 发管理员 GET 并保存预览，无 POST；`send --dry-run` 完全离线。

此版本同步 V4 修复 `46c4bf9537a84188dc78f28f8d157947a6409dde` 的服务端契约：一个批次执行、一个 EER、一次企微任务创建，返回完整 `target_references` 及逐群 `group_deliveries`。只有全部群的真实结果为已发送，整体 `delivery_proven` 才成立。最多 2000 个同一发送成员的目标，超限拒绝；发送前再次检查所有绑定与成员。需要安装对应服务器修复，CLI 更新本身不会改变旧服务器行为；历史原事件和旧逐群任务不自动重发或改写。
