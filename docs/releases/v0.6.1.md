# v0.6.1

本版为 CLI 限制说明、可解释错误及 CRM 专项优化配套客户端。保留 v0.6.0 的命令、参数、成功响应、分页及退出码含义，兼容尚未提供 error_detail 的服务端。

- `docs operation <操作ID>`、`schema get` 和现有搜索入口关联用途限制、原因、来源及恢复方法；同源汇总见 [限制与错误说明书](../crm/limits-and-errors.md)。
- 安全显示服务端已登记的具体原因、字段、实际/上限值和诊断号；未知、非 JSON 或超出读取预算的错误安全回退，不输出任意服务端正文。
- `doctor` 补充服务端能确认的主体、凭据类型与授权来源。继续使用既有 Origin/Codex 凭据隔离，不保存 client secret 或增加自动续期。
- 写入结果未知时继续查询原操作，不自动重发。Codex 升级退出 9 表示本次业务未执行，不重放管道或一次性 stdin。

配套 CRM 服务端修正：缺少、为空或格式错误的 Bearer 返回 401（MCP 保留 JSON-RPC 错误结构）；素材发送用途错误明确为 422，幂等冲突明确为 409；创建计划保留旧摘要/收据并安全重放，回执按页批量读取且实时部分失败保留本地事实。原材料库存储、历史计划和账号归属保留。客户端升级不改变服务端限额、授权或发送状态含义。

旧 CLI 0.6.0 可继续调用新服务端；升级本版后可使用新增说明和错误细节。兼容矩阵、脚本需关注的状态/退出码变化和恢复步骤见 [兼容与恢复](../crm/compatibility-and-recovery.md)。completed 或 provider_accepted 不表示客户已经收到。
