# v0.7.0

新增客户 AI 画像读取命令，按企微 external_userid 或已验证的 UnionID 查询 CRM 既有画像：

```sh
aicrm-cli customers ai-profile get --query external_userid=EXTERNAL_USER_ID
aicrm-cli customers ai-profile get --query unionid=UNION_ID
```

两个标识每次只选一个。返回 `customer_id`、`basic_fields`、`background_fields`、`diagnosis_fields`、`updated_at` 和 `source_version`；复用企微侧边栏的画像读取来源及现有账号、资源权限。此操作只读，不创建客户或触发画像生成。

需要匹配的 CRM 服务端接口 `GET /api/admin/customers/ai-profile`；配套服务端 PR #60 已完成预发并晋级生产，安装源码为 `32a95a412e48bfcc434960856840b099517f157e`。客户端升级不会授予权限。旧命令、认证方式和退出码保持兼容。共享 CLI 来源为 `67c052ffcbd26c11b872dc97d6724ef4d98304e7`，其有效载荷与上述生产源码一致。

发行包覆盖 macOS arm64/amd64、Linux arm64/amd64、Windows amd64，附 `checksums.txt`。macOS、Linux、Windows 原生更新 CI 已通过；生产新接口的认证、参数校验和不存在客户的返回已读回，真实客户画像内容另行验收。
