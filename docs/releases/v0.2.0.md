# v0.2.0：账号 CLI Token 和离线说明书

账号登录使用明确 CLI 入口：无 IP 白名单时 24 小时，有白名单时长期有效并逐次校验来源；不自动续期，不保存登录密码。浏览器密码/企微扫码保持 8 小时。密码重置撤销相应旧账号会话，CLI 策略变更撤销旧 CLI Token。服务器可显式将 Token 保存到新的 0600 文件，默认仍使用系统密钥环。

**兼容要求**：账号新登录要求服务器支持 `POST /api/admin/access/cli/login` 及相应会话/策略迁移。旧的浏览器 Cookie 会话仍按原期限使用；独立机器客户端保持原 OAuth/权限合同。v0.1.4 已有的 HMAC Webhook、全部绑定群读取、冻结请求和结果未知处理均保留。

根 README 增加 AI 入口，提供 `docs search`、`docs operation`、`docs official`、`docs coverage`。命令字段来自编译的 CRM 合同；说明缺失明确标记未知。官方资料与 CRM 字段分开，保留来源、导航层级、日期和正文摘要。下载包附带 README、认证手册、AI 手册及离线官方资料。

目录共 572 项：520 人类账号接口、20 独立机器接口、32 无执行绑定项。官方导航去重为 1,695 篇，取得其中 112 篇的参数表/示例，含 3,907 行表格、273 段示例；1,583 篇正文未取得，原因和逐项覆盖保留，未声称全站正文或逐字段人工核验完成。

客户端 38 个根用例、98 个测试终态通过，无失败/跳过；文档路径占位说明调整后重测 2 个直接用例通过。五个平台构建、压缩包路径/手册内容/摘要和本机二进制离线命令检查通过。跨平台构建不等于每个平台的真实系统密钥环、生产账号或企微 Provider 实测。
