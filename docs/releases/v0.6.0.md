# v0.6.0

新增 48 个已上线 Owner 操作绑定：普通商品 4、客户标签 3、群邀请 9、会员表格 9、素材 14、优惠券 2，以及布局、运行配置、生成明细、手动广播、分渠道回执和专用恢复 7。

沿用原业务服务、权限、事务及外部效果。标签预览与表格 POST 查询按读取授权；优惠券分享和邀请 QR GET 按写入保护。邀请事务已提交但后续失败时返回原计划 ID 和已保存事实，CLI 退出 7 提示查询，不重建或重放。

旧命令与登录方式、Codex 凭据隔离、无 REST 版本检查和原入口升级保持。升级读回成功后自动删除旧版本备份。无数据库迁移，无页面调整。

使用示例和限制见 [能力补齐说明](../crm/capability-completion.md)。服务端候选必须先安装；异步受理不等于真实企微执行。
