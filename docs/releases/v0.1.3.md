# v0.1.3

按计划一次推送全部绑定群：只提供计划 ID、话术和已有小程序素材 ID，明确加上 `--all-bound-groups`，无需填写 Webhook 引用或群 ID 数组。

```sh
aicrm-cli group-ops webhook push \
  --plan-id 12 \
  --text '这里填写你要推送的话术。' \
  --miniprogram-id 1195 \
  --all-bound-groups
```

自动读取计划及所有绑定页，检查当前启用 Webhook 计划、版本和完整绑定集合。新推送生成随机事件；POST 前保存本机 0600 原始请求快照并输出恢复信息。`--event-id` 支持自动化和恢复：同事件复用原始正文及群范围，输入变化拒绝；写请求不自动重试。

`push --dry-run` 会读取服务器计划/群绑定并保存预览，无 HMAC 读取或 POST。`send --dry-run` 继续完全离线检查完整 JSON。新快照读取使用现有管理员会话；POST 使用独立 HMAC，管理员 Cookie、CSRF、机器令牌不会转发。服务端现有 564 项目录及 54 项群运营管理接口不变；无服务器部署或数据库迁移。

2026-10-14 实际验证：向计划 12「正式群运营计划测试」revision 8 的全部 11 个绑定群提交一段知识库搭建日课话术及启用素材 1195。HTTP 202 返回 run 1、执行 1–11；独立 GET 读回 11 条 `provider_accepted=true`、`provider_receipt_present=true`，全部 `delivery_proven=false`。企微任务创建已验证，运营成员确认和最终群内送达未执行，不作为此版本的完成证据。

35 项客户端测试通过，无失败或跳过，新增 7 项按计划推送用例，包含 105 群完整分页、精确范围和凭据隔离、自动事件/预览、固定快照重放、输入冲突、绑定变化/空群/分页异常、持久化失败/损坏、结果未知不重试和管理员授权边界。发行覆盖 Mac/Linux arm64 与 amd64、Windows amd64；归档校验见 `checksums.txt`。
