# v0.8.0

新增按群邀请计划查询企业微信客户群实时成员的命令。

```sh
aicrm-cli group-invitations group-invitation-plans list
aicrm-cli group-invitations group-invitation-plan-members list --param id=YOUR_PLAN_ID --all --format ndjson
```

CLI 按计划逐群返回群名、人数、成员名字、群昵称和成员类型。用 `--all` 读取全部已记录绑定，包括仍保留在计划上的已轮出群。轮出绑定带 `retired` 标记。

这项只读操作由 CRM 服务端使用现有客户联系凭据调用企微客户群详情接口，需要已安装对应路由，由超级管理员以本人账号登录。已在生产验证实时名单读取及名单行数核对。原生自动建群计划的覆盖范围以 CRM 已记录的绑定为准。

发行包提供 macOS arm64/amd64、Linux arm64/amd64、Windows amd64 五种构建及 SHA-256 校验文件。
