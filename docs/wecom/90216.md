## 官方接口地址（资料）

- `https://qyapi.weixin.qq.com/cgi-bin/tag/list?access_token=ACCESS_TOKEN`

## 参数/说明表 1

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access_token | 是 | 调用接口凭证 |

## 参数/说明表 2

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
| taglist | 标签列表 |
| tagid | 标签id |
| tagname | 标签名 |

## 官方代码示例 1（仅供阅读）

```
{
   "errcode": 0,
   "errmsg": "ok",
   "taglist":[
      {"tagid":1,"tagname":"a"},
      {"tagid":2,"tagname":"b"}
   ]
}
```
