## 官方接口地址（资料）

- `https://qyapi.weixin.qq.com/cgi-bin/get_jsapi_ticket?access_token=ACCESS_TOKEN`
- `https://qyapi.weixin.qq.com/cgi-bin/ticket/get?access_token=ACCESS_TOKEN&type=agent_config`

## 参数/说明表 1：获取企业 jsapi_ticket

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access_token | 是 | 调用接口凭证， 企业内部开发，获取方式参考“获取 access_token” 第三方应用开发，获取方式参考“获取企业凭证” |

## 参数/说明表 2：获取企业 jsapi_ticket

| 参数 | 说明 |
| --- | --- |
| ticket | 生成签名所需的 jsapi_ticket，最长为512字节 |
| expires_in | 凭证的有效时间（秒） |

## 参数/说明表 3：获取应用 jsapi_ticket

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access_token | 是 | 应用的调用接口凭证， 企业内部开发，获取方式参考“获取 access_token” 第三方应用开发，获取方式参考“获取企业凭证” |

## 参数/说明表 4：获取应用 jsapi_ticket

| 参数 | 说明 |
| --- | --- |
| ticket | 生成签名所需的 jsapi_ticket，最长为512字节 |
| expires_in | 凭证的有效时间（秒） |
