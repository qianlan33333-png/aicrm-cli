## 官方接口地址（资料）

- `https://qyapi.weixin.qq.com/cgi-bin/user/convert_to_openid?access_token=ACCESS_TOKEN`
- `https://qyapi.weixin.qq.com/cgi-bin/user/convert_to_userid?access_token=ACCESS_TOKEN`

## 参数/说明表 1：userid转openid

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access_token | 是 | 调用接口凭证 |
| userid | 是 | 企业内的成员id |

## 参数/说明表 2：userid转openid

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
| openid | 企业微信成员userid对应的openid |

## 参数/说明表 3：openid转userid

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access_token | 是 | 调用接口凭证 |
| openid | 是 | 在使用企业支付之后，返回结果的openid |

## 参数/说明表 4：openid转userid

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
| userid | 该openid在企业微信对应的成员userid |
