## 官方接口地址（资料）

- `https://qyapi.weixin.qq.com/cgi-bin/tag/create?access_token=ACCESS_TOKEN`

## 参数/说明表 1

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access_token | 是 | 调用接口凭证 |
| tagname | 是 | 标签名称，长度限制为32个字以内（汉字或英文字母），标签名不可与其他标签重名。 |
| tagid | 否 | 标签id，非负整型，指定此参数时新增的标签会生成对应的标签id，不指定时则以目前最大的id自增。 |

## 参数/说明表 2

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
| tagid | 标签id |
