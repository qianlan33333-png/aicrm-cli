## 官方接口地址（资料）

- `https://qyapi.weixin.qq.com/cgi-bin/user/batchdelete?access_token=ACCESS_TOKEN`

## 参数/说明表 1

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access_token | 是 | 调用接口凭证 |
| useridlist | 是 | 成员UserID列表。对应管理端的账号。最多支持200个。若存在无效UserID，直接返回错误 |

## 参数/说明表 2

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
