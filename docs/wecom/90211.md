## 官方接口地址（资料）

- `https://qyapi.weixin.qq.com/cgi-bin/tag/update?access_token=ACCESS_TOKEN`

## 参数/说明表 1

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access_token | 是 | 调用接口凭证 |
| tagid | 是 | 标签ID |
| tagname | 是 | 标签名称，长度限制为32个字（汉字或英文字母），标签不可与其他标签重名。 |

## 参数/说明表 2

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
