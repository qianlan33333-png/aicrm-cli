## 参数/说明表 5：API接口协议

| 错误码 | 错误描述 | 解决方式 |
| --- | --- | --- |
| CA_ERROR | 请求未携带证书，或请求携带的证书出错 | 到商户平台下载证书，请求带上证书后重试。 |
| SIGN_ERROR | 微信支付签名错误 | 按文档要求重新生成签名后再重试。 |
| NO_AUTH | 没有权限 | 请联系微信支付开通api权限 |
| NOT_FOUND | 指定单号数据不存在 | 查询单号对应的数据不存在，请使用正确的商户订单号查询 |

| PARAM_ERROR | 参数错误 | 请查看err_code_des，修改设置错误的参数 |
