# 获取注册码

[企微官方原文](https://developer.work.weixin.qq.com/document/path/90581)

核对日期：2026-10-15；官方 doc_id：14934；原始页面 SHA-256：`1449ea85e864521555526fd98dd0e3e612968a723ee255a1eebb121e701eb4fd`。

本页仅整理官方参数表、示例及接口地址。机械提取不等于逐字段人工核验；未提取的叙述、权限前提、适用版本和调用限制仍以官方原文为准。示例身份和凭据是资料占位，不用于实际调用。

适用导航：

- 第三方应用开发 → 服务端API → 推广二维码 → 调用接口 → 获取注册码（90581）
- 推广二维码 → 调用接口 → 获取注册码（90805）

## 官方接口地址（资料）

- `https://qyapi.weixin.qq.com/cgi-bin/service/get_register_code?provider_access_token=PROVIDER_ACCESS_TOKEN`

## 参数/说明表 1

| 参数 | 是否必须 | 说明 |
| --- | --- | --- |
| provider_access_token | 是 | 服务商provider_access_token，获取方法参见服务商的凭证 |
| template_id | 是 | 推广包ID，最长为128个字节。在“服务商管理端-应用管理-推广二维码”，创建的推广码详情可查看。 |
| corp_name | 否 | 企业名称 |
| admin_name | 否 | 管理员姓名 |
| admin_mobile | 否 | 管理员手机号 |
| state | 否 | 用户自定义的状态值。只支持英文字母和数字，最长为128字节。若指定该参数， 接口 查询注册状态 及 注册完成回调事件 会相应返回该字段值 |
| follow_user | 否 | 跟进人的userid，必须是服务商所在企业的成员。若配置该值，则由该注册码创建的企业，在服务商管理后台，该企业的报备记录会自动标注跟进人员为指定成员 |

## 参数/说明表 2

| 参数 | 说明 |
| --- | --- |
| errcode | 错误码 |
| errmsg | 错误码对应的描述 |
| register_code | 注册码，只能消费一次。在访问注册链接时消费。最长为512个字节 |
| expires_in | register_code有效期，生成链接需要在有效期内点击跳转 |
