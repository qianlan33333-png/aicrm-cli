## 官方接口地址（资料）

- `https://qyapi.weixin.qq.com/cgi-bin/batch/invite?access_token=ACCESS_TOKEN`

## 参数/说明表 1

| 参数 | 是否必须 | 说明 |
| --- | --- | --- |
| access_token | 是 | 调用接口凭证 |
| user | 否 | 成员ID列表, 最多支持1000个。 |
| party | 否 | 部门ID列表，最多支持100个。 |
| tag | 否 | 标签ID列表，最多支持100个。 |

## 参数/说明表 2

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
| invaliduser | 非法成员列表 |
| invalidparty | 非法部门列表 |
| invalidtag | 非法标签列表 |
