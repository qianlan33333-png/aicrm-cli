## 官方接口地址（资料）

- `https://qyapi.weixin.qq.com/cgi-bin/department/delete?access_token=ACCESS_TOKEN&id=ID`

## 参数/说明表 1

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access_token | 是 | 调用接口凭证 |
| id | 是 | 部门id。（注：不能删除根部门；不能删除含有子部门、成员的部门） |

## 参数/说明表 2

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |

## 官方代码示例 1（仅供阅读）

```
{
   "errcode": 0,
   "errmsg": "deleted"
```
