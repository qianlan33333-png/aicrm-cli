# 获取预授权码

核对日期：2026-10-15；官方 doc_id：14940；正文 SHA-256：`aa5c66a9dbe55e3ac1fa430227fd40ed1dba5121a49162b2cda6101652ee2c2f`。

本页仅整理官方参数表、示例及接口地址。机械提取不等于逐字段人工核验；未提取的叙述、权限前提、适用版本和调用限制仍以官方原文为准。示例身份和凭据是资料占位，不用于实际调用。

## 官方接口地址（资料）

- `https://qyapi.weixin.qq.com/cgi-bin/service/get_pre_auth_code?suite_access_token=SUITE_ACCESS_TOKEN`

## 参数/说明表 1

| 参数 | 是否必须 | 说明 |
| --- | --- | --- |
| suite_access_token | 是 | 第三方应用access_token,最长为512字节 |

## 参数/说明表 2

| 参数 | 说明 |
| --- | --- |
| pre_auth_code | 预授权码,最长为512字节 |
| expires_in | 有效期（秒） |
