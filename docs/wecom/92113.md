## 官方接口地址（资料）

- `https://qyapi.weixin.qq.com/cgi-bin/externalcontact/list?access_token=ACCESS_TOKEN&userid=USERID`

## 参数/说明表 1

| 应用类型 | 权限要求 |
| --- | --- |
| 自建应用 | 配置到「客户联系 可调用接口的应用」中 |
| 代开发应用 | 具有「客户基础信息」权限 |
| 第三方应用 | 具有「客户基础信息」权限； 营销获客类应用具有「建联客户信息」权限 |

## 参数/说明表 2

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access_token | 是 | 调用接口凭证 |
| userid | 是 | 企业成员的userid |

## 参数/说明表 3

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
| external_userid | 外部联系人的userid列表 |
