## 参数/说明表 1：加解密库的返回码

| 返回码 | 说明 |
| --- | --- |
| -40001 | 签名验证错误 |
| -40002 | xml/json解析失败 |
| -40003 | sha加密生成签名失败 |
| -40004 | AESKey 非法 |
| -40005 | ReceiveId 校验错误 |
| -40006 | AES 加密失败 |
| -40007 | AES 解密失败 |
| -40008 | 解密后得到的buffer非法 |
| -40009 | base64加密失败 |
| -40010 | base64解密失败 |
| -40011 | 生成xml/json失败 |
